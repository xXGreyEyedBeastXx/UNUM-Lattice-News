```

**Routing does not create corroboration.**

**Mailbox delivery does not create corroboration.**

**Republication does not create corroboration.**

# 5. Source archive and survival rules

Preferred Intake front doors:

```text
sources/README.md
sources/REGISTRY.yaml
schemas/SOURCE_RECORD_v0_1.yaml
docs/EVIDENCE_SURVIVAL_AND_OFFLINE_MIRROR_POLICY_v0_1.md
```

Canonical source layout:

```text
sources/
  <source-id>/
    SOURCE.yaml
    items/
      <year>/
        <item-id>/
          RECORD.yaml
          EXCERPTS.md
          ACCESS_LOG.yaml
          HASHES.yaml
          ROUTES.yaml
```

Create a source folder on first material use. Create item folders when the item receives claim extraction, revision history, or archival material. Avoid empty bureaucratic folders for unreviewed noise.

Source folder != endorsement.

```text
source_exists != source_reliable_on_every_claim
primary_source != neutral_source
official_source != independent_adjudication
publisher_reputation != claim_truth
source_disappearance != source_falsehood
source_persistence != source_truth
```

For ordinary copyrighted journalism, default to:
- metadata;
- stable identifiers;
- original URL;
- bounded excerpts where evidentially necessary;
- access/correction/revision log;
- lawful archive/mirror pointers;
- hashes only when a lawful snapshot is actually held.

Do not make a live URL the only body of the evidence.

Useful survival ladder:

```text
L0 live URL
L1 source metadata + stable identifiers
L2 access / correction / revision log
L3 bounded evidentiary excerpts
L4 hashes of lawfully held snapshot
L5 lawful local snapshot / public-record export
L6 offline manifest + multi-medium mirror
L7 independently hosted / geographically separate mirror
```

A hash proves identity with captured bytes, not factual truth.

# 6. Keep time and state separate

When material, preserve:

```text
event_time
publication_time
observation_time
access_time
state_as_of
correction_time
```

Three useful clocks:

```text
world-state clock
  what actually happened / changed

evidence-state clock
  what evidence became available / changed

projection-rhetoric clock
  what actors or institutions claimed / framed / reclassified
```

Locks:

```text
new article != new event
new evidence != changed historical occurrence
correction != new world event
new litigation around old mechanism != automatically new underlying mechanism
preparedness signal != realized disaster
```

Future seats used in the archive may include:

```text
PAST_EVENT
CURRENT_STATE
FUTURE_SCHEDULED
