
## Failure: “balance” changes the proposition.
**Repair:** seat before qualifier; edge before balance. If the favorable fact does not update the exact proposition, mark `NON_RESPONSIVE`.

## Failure: legal protection erases conduct.
**Repair:** separate conduct, legality, criminal-law fit, immunity, enforceability, and accountability access.

## Failure: blocked action is treated as nonexistent.
**Repair:** preserve `ATTEMPT` and `CONSTRAINT_RESISTANCE` independently from `REALIZED_OUTCOME`.

## Failure: specialist inference silently becomes Lattice fact.
**Repair:** specialist returns a scoped result with source pointers and uncertainty. Intake/Main adjudicates crossing.

## Failure: giant historical lineage becomes one causal sentence.
**Repair:** each arrow gets its own edge class and evidence state: direct implementation, funding transmission, personnel transmission, strategic convergence, field continuity, or unproven resemblance.

## Failure: money is treated as either proof of corruption or irrelevant unless a bribe is proven.
**Repair:** trace access, incentive, ownership, procurement, beneficiary, burden, and timing edges separately. Money may be causally relevant before a corruption finding is earned.

## Failure: state/alliance status assigns aggressor or defender role.
**Repair:** reconstruct prior condition, initiating coercion, response, counter-response, and later independent acts before applying the label.

## Failure: a locally extreme-sounding fact gets softened merely because it sounds implausible.
**Repair:** plausibility of tone is not an evidentiary constraint. Do not exaggerate; also do not normalize away documented conduct.

# 14. Before writing anything consequential

Use this checklist:

- [ ] Did I find the existing object/seat first?
- [ ] Is this a new event, new evidence, new rhetoric, correction, or route?
- [ ] Did I identify the underlying source lineage?
- [ ] Did I preserve event/publication/access/correction clocks where material?
- [ ] Did I bound the exact claim being updated?
- [ ] Did I type the evidence effect?
- [ ] Did I preserve uncertainty and typed missingness?
- [ ] Did I separate mechanism from motive?
- [ ] Did I reconstruct causal role before aggressor/defender/security labels?
- [ ] If cross-border/state/bloc context matters, did I route the right question to Geopolitics?
- [ ] If material flows/ownership/procurement/access matter, did I route the right question to Capital and Power?
- [ ] Did I avoid converting official language into independent truth?
- [ ] If routing to a specialist, did I keep News evidence custody and return path?
- [ ] If promoting harm, is the exact harm edge high-confidence rather than merely alarming?
- [ ] If applying a criminal label, are statutory elements/mental state supported?
- [ ] If the user limited write scope, am I obeying it?
- [ ] Am I writing to `main` rather than creating a branch the user did not request?

# 15. What a good handoff to the next chat looks like

A handoff should be small enough to use, but specific enough to recover:

```text
CURRENT QUESTION
What are we trying to determine?

CURRENT SEAT
Which repo/file owns the present decision?

SOURCE LINEAGE
What primary/best evidence is already in custody?

WHAT CHANGED
World-state, evidence-state, rhetoric/projection, correction, or route?

EARNED FINDINGS
Only the claims/edges currently supported.

OPEN EDGES
Exact missing evidence that would change the assessment.

ROUTES
Specialists to consult and what question each is allowed to answer.
For geopolitical questions: state the exact cross-border/causal-role question.
For capital-power questions: state the exact flow/ownership/beneficiary/incidence question.

RETURN PATH
Where the result must come back.

WRITE BOUNDARY
Which repositories are authorized for writes in this session?
```
