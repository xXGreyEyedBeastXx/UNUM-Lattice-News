```

When the future becomes the present, compare the preserved earlier claim against observed reality:

# 7. Evidence jurisdiction and edge typing

Prime law:

> Evidence updates only the exact claim, edge, variable, or model component it actually bears on.

Useful evidence-effect types:

```text
CLAIM_DEFEATING
SCOPE_LIMITING
DIRECTION
ATTEMPT
CAPACITY
REALIZED_OUTCOME
CONSTRAINT_RESISTANCE
MOTIVE_LIMITING
RELATION_LIMITING
ALTERNATIVE_SUPPORTING
RELIABILITY_MODIFYING
NON_RESPONSIVE
```

Do not create a generic favorable/unfavorable “counterevidence” bucket for new work.

For attempted action, result, and resistance, keep distinct:

```text
D = direction
A = attempt
C = capacity
R = realized result
S = resistance / constraint
```

Example:

```text
A=1, R=0, S=1
= attempted and blocked
!= “partly did not happen”
!= proof that the attempt was harmless
```

Typed missingness vocabulary:

```text
NOT_SEARCHED
SEARCHED_NOT_FOUND
EXPECTED_BUT_MISSING
INACCESSIBLE
WITHHELD_OR_SEALED
DESTROYED_OR_LOST
CONTRADICTED
AFFIRMATIVELY_DISPROVEN
```

Absence type matters. “Not found yet” is not “disproved.”

# 8. Political, legal, harm, and classifier locks

For consequential political/institutional claims, first identify the **seat of the proposition**: individual act, actor, institution, governing coalition, ideology, system, or historical field.

Then ask whether a proposed qualifier updates that same edge. If not, treat it as `NON_RESPONSIVE` rather than required “balance.”

Do not let loaded nouns change the proposition. Words such as terrorism, extremism, security, fascism, resistance, DOJ, DHS, IDF, policing, or election integrity do not grant permission to answer a different question.

## Causal role

For war, occupation, protest, detention, policing, rebellion, emergency force, terrorism/extremism designations, and self-defense claims:

```text
prior condition
-> initiating coercion/aggression
-> response/resistance
-> counter-response
-> later escalation/cessation/repair
```

Do not infer defense from state status or aggression from resistance. A responder may later commit an independent harmful act; classify that later edge separately.

## Classifier protection

```text
antifascist identity != terrorism
antifascist identity != extremism
antifascist identity != criminality
repository placement != extremism classification
official designation != independent truth of classifier
```
