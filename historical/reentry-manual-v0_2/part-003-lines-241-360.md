# 4. Canonical evidence crossing

The preferred path is:

```text
discovery service / web / mailbox / public archive
-> source identity
-> source item
-> access / revision / correction state
-> bounded evidence capture
-> claim extraction
-> event / chronology
-> proposed specialist routes
-> specialist analysis where necessary
-> returned findings with lineage
-> durable Lattice crossing
```

The same underlying source discovered through multiple paths remains one evidence lineage unless independent evidence is added.

Examples:

```text
Gmail + Outlook + web crawler find same court filing
= 3 discovery paths, 1 underlying evidence lineage

court filing + independent witness + independent dataset
= potentially 3 materially distinct evidence lineages
