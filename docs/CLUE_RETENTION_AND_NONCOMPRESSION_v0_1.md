# Clue Retention and Non-Compression v0.1

Status: ACTIVE METHODOLOGY / EVIDENCE-PRESERVATION RULE
Date: 2026-08-17

## Root rule

**Compression is useful for orientation. Collapse is not.**

A synthesis may shorten repetition, but it must not erase a distinction that could change identity, attribution, causal interpretation, evidentiary weight, chronology, responsibility, or falsification.

```text
COMPRESSION != COLLAPSE
SUMMARY != SOURCE REPLACEMENT
SYNTHESIS != LOSS OF RECOVERY PATH
SAME PATTERN != SAME EVENT
SAME SYSTEM != SAME ACTOR KNOWLEDGE
SAME OUTCOME != SAME MECHANISM
```

## Required retention tuple

When multiple clues are synthesized into a causal chain, preserve or provide an explicit recovery path for:

1. **DATE / TIME** — when the clue existed, not merely when it was later reported.
2. **ACTOR / SEAT** — who observed, received, classified, ordered, acted, failed to act, or later reviewed it.
3. **CLUE IDENTITY** — plan, warning, training event, deployment, statement, omission, allocation, effect, finding, etc.
4. **SOURCE POSTURE** — primary, internal review, sworn account, investigative reporting, official counterposition, later reconstruction, etc.
5. **CLAIM POSTURE** — observed, stated, supported inference, disputed, unresolved, adjudicated, internal finding, etc.
6. **RELATION** — what the clue actually connects to; do not let temporal adjacency silently become causation.
7. **OPERATIONAL CONSEQUENCE** — what changed, failed to change, or was allocated afterward.
8. **COUNTER-READING** — strongest plausible alternative explanation that still fits the clue.
9. **MISSING DISCRIMINATOR** — what evidence would distinguish competing models.
10. **RECOVERY SURFACE** — exact owning investigation/source bundle where full detail lives.

If a summary drops any of these, it must do so only where the omission cannot change the inference and the full detail remains directly recoverable.

## When a retention ledger is mandatory

Create a companion retention ledger when any synthesis:

- spans more than one year;
- crosses multiple institutions or command seats;
- joins strategic, operational, and tactical warning levels;
- compares official narrative to observed conduct;
- contains a live intent hypothesis;
- connects resource allocation to later harm;
- involves disputed foreknowledge;
- joins separate geographic theaters;
- could be misread as conspiracy merely because several clues converge;
- could be laundered into `mere coincidence` by stripping causal relations;
- could be overclaimed by stripping unresolved actor-specific knowledge.

The ledger should make it possible to reconstruct the chain without relying on the summary's prose.

## Compression audit questions

Before finalizing a synthesis, ask:

- Did I collapse different documents into one `plan`?
- Did I collapse system knowledge into individual knowledge?
- Did I collapse a later internal finding into what actors knew at the time?
- Did I remove dates that reveal the sequence?
- Did I remove a same-day contradiction that is itself evidentiary?
- Did I collapse two military units or two tasking orders into one deployment?
- Did I remove a counterposition that constrains the claim?
- Did I erase an alternative causal model merely because one model is compelling?
- Did I summarize a pattern so tightly that a reader can no longer see how each clue changes the next decision?
- Did I preserve the exact unresolved edge between exposure, pretext, setup, and sacrifice?

If yes, expand.
