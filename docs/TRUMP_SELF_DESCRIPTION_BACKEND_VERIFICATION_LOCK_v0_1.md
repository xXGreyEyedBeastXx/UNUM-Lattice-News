## Rule

For Donald Trump and the Trump administration, favorable self-description is not evidence of favorable effect.

```text
"peace"
"security"
"protect"
"freedom"
"anti-corruption"
"efficiency"
"pro-worker"
"pro-family"
"humanitarian"
"law and order"
"anti-terror"
"election integrity"
"government reform"
```

Each is first recorded as `STATED_POSITION` and, where relevant, `DIRECTION` evidence about the advertised objective.

It does **not** become evidence of realized benefit, harmlessness, legitimacy, necessity, proportionality, or good motive without independent support.

```text

-> evidence that Trump advertised X as beneficial
!= evidence X was beneficial

-> REALIZED_OUTCOME for that scoped benefit

```

## Historical credibility posture

Do not use generic personal trust or distrust as a substitute for evidence.

The operative rule is not:

```text
Trump said it -> false
Trump called it good -> evil by definition
```

The operative rule is:

```text
Trump favorable claim -> mandatory independent backend verification
```

When prior documented patterns of misleading, incomplete, contradictory, or strategically framed statements are relevant to source reliability, record them as `RELIABILITY_MODIFYING` evidence tied to the specific source/claim context rather than as a universal truth-value inverter.
