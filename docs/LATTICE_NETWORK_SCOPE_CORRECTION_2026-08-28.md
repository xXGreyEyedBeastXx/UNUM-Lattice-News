# Lattice Network Scope Correction — 2026-08-28

**Status:** ACTIVE CORRECTION / BASELINE ROUTING LOCK

This note corrects one overextension in `docs/BASELINE_LOAD_AND_INFRASTRUCTURE_AUDIT_2026-08-28.md`.

## Research repository role

`UNUM-Research` is **not** a shared Lattice librarian, chronology service, or specialist-analysis owner.

Its intended role is:

```text
research request / candidate
-> UNUM-Research intake and triage
-> destination repository selected
-> destination repository performs the actual study
-> destination repository owns local synthesis / dissemination
-> earned findings may return to Lattice News through normal evidence-bearing crossings
```

Research may collect requests, candidate questions, source leads, and routing suggestions. It does not inherit the destination repository's study or dissemination authority.

## Distinguish the two intake seats

```text
UNUM-Lattice-News-Intake
= public-news/source intake
= source verification
= claim extraction
= clocks / evidence-state handling
= proposed Lattice routes

UNUM-Research
= general cross-repository research-request intake
= research candidate triage
= likely destination selection
= dispatch to the repository that should actually study the question
```

Neither intake seat should become a universal study repository.

## Current Lattice infrastructure focus

For the present baseline-building phase, the working network is:

```text
public reality
-> Lattice News Intake
-> specialist Lattice / sibling study repositories
-> durable Lattice recomposition
-> downstream harm / policy / humanitarian gates
-> Radical Love publication handoff where appropriate
-> Archives for frozen publication history
```

Shared supporting services such as Timeline, Translation, and Tools may reduce duplication where their actual jurisdiction fits, but they do not seize evidence custody.

## Supersession note

The rest of the audit remains useful, especially the priorities around transport identity, shared harm/repair continuity, specialist receiving capacity, and load redistribution.
