## Purpose

The lattice must distinguish prediction from proof without treating forward causal analysis as illegitimate. A future harm can be strongly implied by an active system before the endpoint has occurred.

## Core distinction

**Trajectory-inevitable** does not mean metaphysically or unconditionally unavoidable.

It means:

> If the identified causal dynamics continue substantially unchanged and no sufficiently strong countervailing intervention alters the course, the modeled endpoint follows from the trajectory.

A successful intervention changes the trajectory; its mere theoretical availability does not falsify a trajectory-inevitability claim.

## Future-state classes

- `POSSIBLE`: current mechanisms permit the outcome.
- `PROBABLE`: current evidence and constraints make the outcome more likely than relevant alternatives.
- `TRAJECTORY_INEVITABLE`: continuation of the current causal course yields the endpoint; avoiding it requires course change.
- `OBSERVED_ENDPOINT`: the projected state has materially occurred.

Do not promote between classes without evidence.

## Projection packet

Every strong future-harm projection should preserve:

1. `observed_state` — enacted policy, conduct, capability, rhetoric, institutions, material conditions.
2. `active_causal_mechanisms` — mechanisms capable of transporting the system toward the endpoint.
3. `direction_of_travel` — what is increasing, decreasing, concentrating, criminalizing, excluding, or becoming easier/harder.
4. `projected_endpoint` — the harm/state being forecast.
5. `trajectory_confidence` — confidence that unchanged dynamics reach the endpoint.
6. `critical_crossings` — transitions that have not yet occurred and must not be silently treated as observed.
7. `trigger_indicators` — observations that promote a risk pathway toward emerging/observed reality.
8. `countervailing_constraints` — courts, elections, federalism, institutional resistance, public action, economic constraints, statutory protections, etc.
9. `minimum_course_correction` — smallest intervention capable of breaking the chain.
10. `falsifiers` — observations that would materially weaken the projected pathway.

## Important reasoning rule

Countervailing institutions are not automatically rebuttals to trajectory inevitability.

If the claim is `on the current course X follows`, then a court, election, statute, institutional refusal, or public intervention that successfully blocks a causal link changes the course. The projection should be updated from that new state.

## Harm-chain representation

```text
observed state
    -> causal mechanism
    -> intermediate state
    -> critical crossing
    -> projected harm

         ^
         |
countervailing constraint
         |
   course correction
```

Never erase an unobserved crossing. Never describe a projected endpoint as already occurring merely because the path toward it is concerning.

## Threat-analysis heuristic

A useful qualitative model is:

`future harm pressure = capability + stated intent + enacted/proposed policy direction + interacting mechanisms + historical/empirical analogues - effective countervailing constraints`

This is a reasoning scaffold, not a numerical equation unless independently operationalized.

## Provenance rule

Every projection should remain reconstructable backward from endpoint to evidence. Preserve dates so later investigators can distinguish genuine foresight from retrospective narrative fitting.

## Correction rule

When the trajectory changes, do not delete the old forecast. Date the intervention, mark which causal edge broke or weakened, and recompute from the new state.

The purpose of prediction is not to be vindicated by harm. The preferred outcome is that a sufficiently early warning helps prevent the projected endpoint.
