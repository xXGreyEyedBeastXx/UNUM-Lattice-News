# Relational Enclosure / News State Alignment v0.1

**Status:** ACTIVE_REVIEW / EVIDENCE-BOUND ADAPTATION  
**Operational companion:** `docs/NEWS_STATE_TRANSITION_MODEL_v0_1.md`  
**Structured surface:** `schemas/NEWS_STATE_TRANSITION_v0_1.yaml`

News does not inherit physical ontology from the Holo Mesh. It can reuse the relation and transformation grammar for evidence-traced public-state analysis where that grammar preserves real distinctions.

The purpose of this bridge is not to make journalism look like physics. It is to prevent public-state reporting from collapsing the intermediate spaces between event, evidence, relation, constraint, transformation, projection, and later correction.

## Three co-present questions

For a bounded story/event/state, preserve:

```text
difference
  what changed, diverged, accumulated, or became newly observable?

bounded state
  what entity/event/institutional configuration is actually supported by the evidence at this seat?

surround
  what upstream causes, downstream effects, exchanges, constraints, absences,
  exclusions, counterparties, resistance, and lost/unobserved information condition the read?
```

The bounded state is a seated read, not a claim that everything outside the boundary is irrelevant.

## The intermediate crossing

Where a story materially changes the recoverable public state, preserve:

```text
prior supported state
-> event / operation / pressure / observation / correction
-> later supported state
```

Do not compress the crossing into prose when the missing structure changes interpretation.

At minimum ask:

- what changed;
- what stayed continuous;
- what became newly known rather than newly real;
- which clock the date belongs to;
- what resistance or opposing pressure altered the result;
- which evidence item bears on which delta;
- what remains unresolved;
- what later evidence would change the read.

The active operational grammar for this crossing is `docs/NEWS_STATE_TRANSITION_MODEL_v0_1.md`.

## Clock separation

A public event can occupy several non-identical time seats:

```text
event time
publication time
observation time
investigator access time
state-as-of time
correction time
```

Locks:

```text
late publication != late event
new article != new event
new evidence != changed historical occurrence
correction of a claim != erasure of the earlier record
```

## Two- or multi-seat comparison

For two actors/events/states, compare typed relations rather than proximity alone:

```text
shared evidence
shared upstream cause
direct contribution
exchange
exclusion / constraint
common environment
surviving relation across a transformation
opposing pressure / resistance
projection / co-occurrence only
unknown
```

Where more than two seats matter, preserve the same rule: comparison does not itself create a causal edge.

## Balance is not absence

Opposing pressures may cancel in a net read while both remain causally important.

```text
pressure A + pressure B -> low or zero net delta
```

This does not justify deleting either pressure.

A State Drive-style trace should preserve the directional components, the counterforce, the affected seat, and the surviving relation rather than storing only the net outcome.

## Projection versus material state

Keep separate:

```text
what an actor says changed
what a source reports changed
what the evidence establishes changed
what merely changed in framing or discoverability
what remains disputed
```

A projection change may be news in its own right, but it is not automatic evidence of a material-state change.

## Continuity through reseating

Legal, organizational, accounting, jurisdictional, branding, office, or program changes may alter the address without terminating the relation.

Apply the mesh locks:

```text
name change != identity change
legal separation != causal separation
accounting separation != material separation
```

Preserve both the changed address and any evidenced continuity.

## Evidence jurisdiction

Evidence updates only the relation, delta, variable, or claim component it actually bears on.

Examples:

```text
successful court resistance
-> result / resistance update
!= automatic erasure of attempted direction

new denial
-> stated / projection update
!= automatic material reversal

newly recovered document
-> evidence-state update
!= proof the underlying event occurred on recovery day
```

## Core locks

```text
co-occurrence != coordination
shared projection != shared cause
contribution != culpability
zero net change != no opposing pressures
repeated citation lineage != independent evidence
new publication != new state transition
state snapshot != permanent identity
state transition != moral verdict
```

A State Drive-style trace can preserve how a public state changed over time; Atlas-style comparison can preserve multiple evidence-qualified maps. Neither upgrades inference to fact.

## Re-entry

A later reviewer should be able to reconstruct:

```text
before
crossing
after
clocks
changed relations
surviving relations
opposing pressures
weak edges
source lineage
correction path
```

If those cannot be recovered, the news-state layer has been compressed too aggressively.

Tiny lock:

```text
Track the state and the surround.
Separate causal crossing from projected overlap.
Preserve opposing pressures at balance.
Preserve the clock that each date belongs to.
Let evidence type the relation and the delta.
```
