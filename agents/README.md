## How to treat files here

These files may still be useful for:

- public method transparency;
- historical development and provenance;
- checking whether a specialized discrimination was lost during Backend adaptation;
- migration archaeology.

They should **not** be treated as the current place to run or evolve Lattice operational agents.

If a useful capability is discovered here that Backend lacks:

```text
identify the exact capability
-> adapt it into Backend
-> verify the Backend owner
-> record the migration
-> keep or retire the public copy according to public-method value
```

Do not add new operational agents here.

Where multiple versions exist, version history remains useful migration evidence. Presence of an older file does not make it current operational authority.
