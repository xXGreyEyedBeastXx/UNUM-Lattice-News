# Robert F. Kennedy Jr. — Living Dossier

This directory is an additive dossier surface for the canonical actor node at `../robert-f-kennedy-jr.yaml`.

The canonical node remains authoritative for stable identity and typed relations. This dossier may accumulate claims, actions, rhetoric, harms, sources, bridges, stitches, corrections, and cross-node pointers without forcing every evolving investigation into the canonical node itself.

## Dossier rules

- Preserve claim posture and investigation state.
- Keep documented relation separate from inferred coordination, capture, motive, or intent.
- Prefer pointers to canonical claim/source objects over duplicated evidence.
- A bridge describes a typed crossing between domains or node families; it does not establish identity.
- A stitch records a local connection that can be traced back to its source lineage.
- Corrections and supersession remain visible.
