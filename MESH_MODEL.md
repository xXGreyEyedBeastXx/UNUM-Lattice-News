## Terminology lock

The repository stores **lattice records** but investigates a **mesh**.

- **Lattice** = durable record/index surface: sources, stories, nodes, relations, claims, contributions, spreads, corrections, schemas, and dated projections.
- **Mesh** = the worldly and evidentiary topology those records jointly recover: overlapping identities, kinship, money, labor, land, contracts, ownership, coercion, narratives, law, administrative action, information lineage, harm, gain, power, and redress.

A node is an addressable seat in the mesh. It is not a primitive, wall, verdict, or complete identity.
A relation is a typed crossing. It is not the whole relationship.
A category routes investigation. It does not prove causal discontinuity.

## Root invariant

```text
different name != independent body
same relation != same body
legal separation != causal separation
accounting separation != material separation
jurisdictional separation != power separation
repeated citation != independent evidence
formal consent != substantive voluntariness
legality != legitimacy
benefit recipient != terminal beneficiary
```

Resolve identity before accepting separation. Resolve relations before declaring independence.
Keep distinct bodies distinct, but never sever an evidenced relationship merely because names, legal forms, jurisdictions, programs, accounts, or public narratives change.

## Mesh traversal

Investigations may enter anywhere.

```text
entry seat
-> identity / kinship resolution
-> relation expansion
-> constraint envelope
-> material / money / labor / resource flow
-> transformation
-> harm and gain distribution
-> terminal or reseated ownership / capacity
-> narrative / legality / truth-production layer
-> redress / correction path
-> feedback into the next cycle
```

The first visible surface is not presumed to be the causal beginning.

For any apparent endpoint, ask:

1. Did the thing actually terminate here, or was it renamed?
2. Did the actor change identity, or merely legal form, brand, subsidiary, trust, fund, office, contractor, or jurisdiction?
3. Did money become revenue, margin, interest, rent, equity, executive compensation, dividends, buybacks, asset appreciation, debt service, public capacity, surveillance capacity, coercive capacity, or political insulation?
4. Did harm become a legal category, administrative routine, market outcome, externality, eligibility rule, security measure, or private contract?
5. Did one source become ten apparent sources through citation inheritance?
6. Did nominal choice occur inside a constraint envelope that made refusal, exit, or bargaining unrealistic?
7. Did a correction path actually return, or was it captured, delayed, defunded, intimidated, bypassed, or converted into theater?

## Decompose and recompose

```text
separate for attribution
-> resolve identity and kinship
-> preserve lineage
-> follow transformations
-> recompose for causation
```

Precision is required. Fragmentation is forbidden.

Anti-double-counting prevents counting the same value twice. It must never be used to erase a downstream seat of the same value.

Uncertainty belongs on the weak edge. It does not authorize deleting the surrounding supported mesh.

## Historical comparative use

Historical cases are not analogy shortcuts or guilt-by-resemblance. They are operator-discovery surfaces.

Rome can reveal public/private extraction, tax farming, conquest wealth, and patronage-return loops.
Nazi Germany can reveal false voluntariness, administrative euphemism, forced-labor/public-private meshes, confiscation, victim-to-resource conversion, and truth laundering.
Stalinist systems can reveal extraction whose terminal gain is state/party/coercive capacity rather than private shareholder wealth, plus captured courts, statistics, press, and correction channels.

The question is always:

> Which transformation recurs, under what constraints, with what evidence, and what would distinguish the present case from the historical mechanism?

## Accusation mirror test

For consequential accusations, test both the allegation and the accuser's conduct without presuming psychological projection.

```text
accusation
-> accused conduct
-> underlying harm mechanism
-> evidence

accuser / allied actor conduct
-> same mechanism | analogous mechanism | materially different | unknown
-> naming difference
-> moral-treatment difference
-> evidence
```

If swapping actor names changes the moral label while the causal mechanism remains materially the same, record candidate **actor-dependent moral laundering**.

## Downward blame / upward extraction test

When a lower-power population is blamed for material pressure:

```text
claimed harm
-> actual pressure measurement
-> all causal contributors
-> who controls the relevant terms
-> who bears the loss
-> who captures wage savings / rent / margin / contract revenue / tax advantage / asset gain
-> who funds or amplifies the causal story
-> what policy follows
-> who gains from that policy
```

Do not confuse contributing to pressure with capturing the gain.

## Closure rule

An investigation may close a path only when the record supports a real termination, not because the next transformation is inconvenient, legally separate, politically uncomfortable, or named differently.

```text
No false disconnects.
No naked crossings.
Weak edges stay weak.
Strong edges stay strong.
The mesh remains traversable.
```
