## Historical-field posture

The correct current seat is no longer:

```text
Powell wrote a memo; maybe later events happened to resemble it.
```

Nor is it:

```text
Powell wrote a memo; therefore every later conservative institution and policy was caused by it.
```

The stronger working model is:

```text
pre-existing business/conservative reaction field
-> explicit strategy articulation and institutional experiments
-> durable organization building
-> litigation / policy / academic / media / donor / personnel capacity
-> later convergence and transmission among conservative institutions
-> organized transition machinery
-> current state-power crossing
```

The **broad lineage is supported enough to study as a connected historical field**. Direct causation remains edge-specific.

## Current-administration discriminator

The current administration matters because the terminal node is not merely ideological similarity. There is realized personnel transfer into state authority.

For each present policy, require:

```text
historical / organizational predecessor
-> Project 2025 or other policy text
-> author / institution / personnel relation
-> current officeholder / decision seat
-> executive / regulatory / budget / enforcement mechanism
-> implementation
-> resistance / constraint
-> realized effect
```

A match at one rung does not silently populate the rest.
